JSON 格式

{
  "board": {"width": 6000, "height": 4000},          // 展板尺寸（整数像素，可达 100000）
  "photos": [                                         // 原片清单
    {"id": "A-001", "credit": "陈晨",
     "permit": {"x": 0, "y": 0, "w": 2400, "h": 1600}}  // 可刊矩形（原片坐标）
  ],
  "pieces": [                                         // 裁片，从下往上排列
    {"photo": "A-001",
     "crop": {"x": 100, "y": 80, "w": 1200, "h": 900},  // 原片裁框（原片坐标）
     "at": {"x": 300, "y": 250}}                        // 落版位置（裁框左上角在展板上的坐标）
  ]
}
  • 所有坐标均为整数像素；裁片按原尺寸铺放、互不透明。
  • 只统计展板范围内、且未被上层裁片遮住的部分；同一原片多处露出重叠时只计一次。
  • 整页无缺口（露出均在可刊矩形内）时才可下载署名 CSV。
